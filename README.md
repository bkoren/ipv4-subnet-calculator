# IPv4 Subnet Calculator
 
A C# console app for IPv4 subnetting.
 
📅 Built in 2023 for the *Introduction to Computer Networks* course at Algebra University.
 
## Features
 
- Convert IP addresses between binary and decimal
- Calculate network address, first/last usable host, and broadcast address
- Find the subnet mask for a given number of devices
- Input validation for invalid IPv4 values
## Run
 
```bash
dotnet run
```
